# Latest Market Map

**Updated**: 2026-04-02

## 목적
이 문서는 최근 검색/회수된 신호를 바탕으로 어떤 아이디어를 유지할지 빠르게 판단하기 위한 최신 요약본이다.

## 핵심 결론
### 1) Primary: Voice-of-Customer Repository
가장 강한 신호는 B2B SaaS 팀이 feedback 자체보다 **decision translation 문제**를 겪고 있다는 점이다.

반복 신호:
- support / churn / feature request / commitment 데이터가 여러 도구에 흩어짐
- Productboard/Jira/Sheet를 써도 discovery와 commitment hygiene가 분리되지 않음
- 월요일/주간 회의 전에 사람이 다시 support, Slack, Salesforce, note를 읽고 정리함
- roadmap, release plan, progress report를 안전하게 분리하는 커뮤니케이션 레이어가 부족함

왜 유지하는가:
- pain이 넓고 깊다
- ICP가 분명하다
- weekly brief라는 출력물이 명확하다
- B2B 팀 단위 과금이 자연스럽다

### 2) Backup: Creator Deal CRM
creator/agency pain은 강하지만, broad CRM보다 **collections visibility + invoice readiness + payment-stage clarity**가 더 날카로운 entry wedge로 보인다.

반복 신호:
- late payment / underpayment / ghosting
- AP contact, PO/reference, payment terms 관리 부실
- promised payment date와 실제 입금의 괴리
- day 3 / day 7 / day 30 follow-up cadence 필요
- vendor onboarding, pay-run miss, intermediary billing chain 같은 payment-stage blockage

왜 backup인가:
- pain은 강하지만 ICP가 solo creator / freelancer / small agency로 조금 섞임
- 현재는 VoC 쪽이 더 문서화/개발 준비도가 높음

## 현재 순위
1. Voice-of-Customer Repository
2. Creator Deal CRM

## 보류한 파생 아이디어
아래 아이디어들은 독립 파일로 유지하지 않고 현재는 파생 모듈/하위 wedge로만 본다.
- Support-to-Product Decision Hub → VoC 하위 wedge
- Churn Decision Copilot → VoC 하위 module
- Creator Collections Assistant → Creator Deal CRM의 entry wedge
